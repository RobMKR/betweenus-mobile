# BetweenUs brand assets

Two rounded cream links form the BetweenUs mark. Their overlapping open ends suggest two people sharing the same space. The dark green field provides contrast at launcher and favicon sizes.

`mark.svg` holds the standalone mark. Expo uses the square icon, the transparent adaptive foreground, the favicon, and the rounded splash badge. The in-app badge uses the same square icon with rounded corners.

Render the SVG sources with Inkscape at these sizes when updating the PNGs.

| SVG | PNG | Dimensions |
| --- | --- | --- |
| `icon.svg` | `icon.png` | 1024 × 1024 |
| `icon.svg` | `favicon.png` | 64 × 64 |
| `adaptive-foreground.svg` | `adaptive-foreground.png` | 1024 × 1024 |
| `badge.svg` | `badge.png` | 512 × 512 |

Export the app icon and favicon as opaque RGB PNGs. Keep transparency in the adaptive foreground and splash badge.
